# Иосиф Правец

**Руководитель отдела разработки, 1С.** Делаю инструменты вокруг платформы 1С:Предприятие:
сборка и CI/CD, валидация конфигураций, плагины для EDT и агентов
с 1С-контекстом. Пишу на том, что решает задачу — Go, Python, Java, Shell, OneScript.

## Чем занимаюсь

- **1С — сборка, контроль качества, CI** — docker-образы платформы, валидатор конфигураций, плагины для EDT
- **Агенты с контекстом 1С и личной вики** — плагины для DeepSeek Harness, каркас вики под LLM
- **Игры и стриминг** — LLM-агенты, MCP-сервер под Forge, стриминг-студия
